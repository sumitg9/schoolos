# School ERP Web

This directory contains the Next.js 16 and TypeScript frontend. The Laravel REST API lives in `../api`.

For full setup, PostgreSQL, and initial administrator instructions, see the [project README](../README.md).

Configure `NEXT_PUBLIC_API_URL` in `.env.local` from `.env.example`, then run:

```powershell
npm install
npm run dev
```

Use `npm run lint` and `npm run build` to validate the frontend.
